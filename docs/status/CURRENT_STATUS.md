# Desktop Companion — CURRENT STATUS

更新日: 2026-09-07

この文書は、このプロジェクトの「現在地」の正本である。
設計判断は `docs/sacred/` の聖典を優先し、現状確認はこの文書を必ず参照する。

## 1. 最上位ゴール

M5Stackを、単なる音声AI端末ではなく、

**「机の上に常にいて、周囲を感じ、反応し、気分が変わり、少しずつ関係性が育つ相棒」**

として成立させる。

評価基準は機能数ではなく、**「そこにいる感じ」があるか**。

## 2. 現在の大きな論点

現状のDesk Bot実装は、聖典Step 0〜11へ正しく再マッピングする必要がある。

現在は局所的なVision修正ではなく、**M5Stack＝身体・低次脳、Pi5＝高次感覚野・認知脳**という全体構造から、知覚・神経・反射・Heart Engine・記憶・身体出力の配置を定義する段階。

## 3. 現在確認できている実装事実

GitHub `Phantom-Theatre88/desktop-companion` の現Yuki実装には、独自LVGLキャラクター表示、瞬き・視線・口・emotion状態、ESP-DL顔検出、顔位置追尾、wave detection、頭タッチ・揺れ等のinteraction取得、LED制御、curiosity自発会話、Xiaozhi音声ランタイム等が存在する。

ただし、コード上の存在と現在の実機正常動作は分けて扱う。

## 4. Visionの現在判断

現状のM5側Visionは、**「見ているが、周囲を意味として認識して身体・心へ渡せている」とは言えない。**

Yuki Visionの局所修正は停止し、`stack-chan-ko` を本体として適合手術を行う。

さらに、最終視覚系は**2カメラ構成**とすることを正式LOCKした。

- **M5Stack側カメラ＝反射の目**：人／顔の存在、位置、動き、単純ジェスチャ等を軽量・低遅延に処理し、視線・首・表情・反射へ接続
- **Pi5側カメラ＝理解する目**：広い視野、高次人物／物体／状況認識、記憶照合、会話・認知への視覚情報供給

Pi5側高次視覚カメラは **Raspberry Pi Camera Module 3 Wide** を採用LOCK。

## 5. 現在確定しているハードウェア

### 感覚器官

購入済み：

- 接触センサー
- 温度センサー
- 湿度センサー
- 距離センサー

これらは単なる値取得機能ではなく、「この子が何を感じられるようになるか」を定義してHeart Engine／反射へ接続する。

既存／構想中のカメラ、マイク、IMU、照度等と合わせ、最終的な感覚野配置を決める。

### Raspberry Pi 5側

- SSD：購入済み
- 高次視覚：**Raspberry Pi Camera Module 3 Wide 採用LOCK**

SSDの具体機種・容量・接続方式は、現時点で確認できていないため推測で固定しない。

## 6. M5Stack／Pi5の役割分担

### M5Stack

**身体＋生命維持できる低次脳＋反射系**。

Pi5が停止しても、見る・感じる・反応する・Heart Engine・基本的自発行動を継続する。

### Raspberry Pi 5

**高次感覚野＋認知脳＋言語＋長期記憶**。

人物・物体・状況理解、高度ASR、会話、LLM、長期記憶照合等を担当する。

## 7. 神経系の共通化

M5Stack内部とM5Stack ↔ Pi5の通信は実装・搬送方式を無理に一本化しない。

ただし、**意味モデル・語彙・ID・payload定義は共通化する。**

原則：**語彙は共通、文法と輸送手段は別。**

具体プロトコルは、最終的な機能配置を洗い出した後に確定する。
