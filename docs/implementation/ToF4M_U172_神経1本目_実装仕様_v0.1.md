# ToF4M U172｜神経1本目 実装仕様 v0.1

更新日: 2026-09-10

## 小ゴール

ToF4M U172を最初の感覚器官として、製品固有の距離値から意味化された近接情報を作り、NeuronとSynapseを通して上位層へ配送できる「神経1本目」の最小骨格を成立させる。

この段階ではToF単独で人物を断定しない。`PERSON_APPROACHING` はTMOS・Vision等とのPerception Integration後に生成する意味であり、ToF単独は `PROXIMITY_*` を出力する。

## 1. 何を感じる感覚か

距離そのものではなく、外界の対象が近づいた／近くにいる／離れたという近接変化を感じる。

## 2. 生データ

U172から取得する距離値。ハードウェアドライバ層のみが製品固有I2C・VL53L1X仕様を知る。

## 3. M5側前処理

`ToF4MPerception` が有効な距離サンプルを受け、前回値と状態を用いて意味化する。

## 4. timestamp / confidence

ハードウェア取得側が `timestamp_ms` と `confidence` をサンプルへ付与する。初期実装ではconfidence算出方式を固定しない。

## 5. 意味化イベント／状態

- `PROXIMITY_APPROACHING`
- `PROXIMITY_NEAR`
- `PROXIMITY_LEAVE`

名称はコード上 `kProximityApproaching` 等で表現する。

## 6. 反射層への入力

Synapseにより `PROXIMITY_APPROACHING` 等をReflex側へ接続できる。ただし具体的なEyes/Neck動作は既存身体制御との競合確認後に接続する。

## 7. Heart Engineへの意味

同一Semantic EventをHeart側Synapseへ配送可能にする。Heart数値仕様は課題3で決めるため、現段階で係数をLOCKしない。

## 8. Pi5へ渡す条件と内容

Pi5送信は神経1本目では未接続。将来、人物識別等の高次認知が必要な時だけSemantic Eventを共通意味として渡す。

## 9. Pi5から返る高次認知

神経1本目では未実装。Pi5結果は将来Semantic Neuronへ戻す。

## 10. Pi5切断時フォールバック

ToF感覚、意味化、M5側Neuron/Synapse、低次反射はPi5なしで継続できる構造とする。

## 11. Behavior Selectorとの接続

神経回路は身体を直接占有しない。反射・Heart等が出す行動要求をBehavior Selectorへ接続する。今回のコードではSynapse配送骨格までとし、既存身体制御への直接接続は行わない。

## 12. Eyes / Neck等の身体出力

初回は未接続。既存Vision追従・会話モーションとの競合を確認してから必要な身体出力だけを要求する。

## 13. ログと実機確認条件

最低限、以下を因果順に追えることを完成条件とする。

`raw distance -> PROXIMITY event -> Synapse delivery -> Reflex/Heart request -> Behavior Selector -> Body Output`

現時点ではハードウェアドライバ・既存Behavior Selectorへの接続・実機ログ確認は未達。

## Neuron / Synapseの今回実装

- Neuron: `SemanticEvent` とその共通語彙
- Synapse: event IDとcallback/contextを結ぶ固定長接続
- NeuralCircuit: Synapse登録とSemantic Event配送
- 動的学習、重み、可塑性、発火閾値は今回の範囲外

## 閾値について

コードには動作確認用の暫定初期値を置くが、正式LOCK値ではない。

- near: 600 mm
- leave: 750 mm
- approaching delta: 80 mm / sample

実機のノイズ・サンプリング周期・机上距離に合わせて評価後に決定する。

## 現在のブロッカー

Yuki本体はESP-IDF 5.5.4ネイティブC/C++。M5Stack公式U172ライブラリはArduino/M5Unit系の利用例が中心であり、そのまま本体へ持ち込まず、ESP-IDF側I2C/センサードライバとの適合方法を確認してからハードウェア取得層を実装する。
