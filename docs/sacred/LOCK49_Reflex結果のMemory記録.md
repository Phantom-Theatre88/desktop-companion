# LOCK 49｜Reflexの結果は、必要に応じてMemoryへ記録する

更新日: 2026-09-17

## 決定
Reflexはその場限りの反応で完結させず、**その反射が起きた原因・反応内容・結果のうち、今後の危険判断や学習に意味があるものはMemoryへ記録できる**構造とする。

これにより、過去の危険経験が次回以降のReflex / Synapse / Heart / Behaviorへ影響する流れを成立させる。

## 基本方針
- Reflexが発生した事実だけを毎回機械的に保存するのではない
- 将来の判断・警戒・学習に意味があるものをMemoryへ残す
- Memoryへ残す内容には、必要に応じて以下を含められる
  - 何が起きたか
  - どのReflexが発動したか
  - 身体がどう反応したか
  - 回避に成功したか／失敗したか
  - 危険が継続したか／解消したか
  - その時のHeart Context
  - その出来事がどの程度強い経験だったか
- Reflexの結果記録は、次回の類似刺激に対するSynapseの通りやすさやReflex感度の修飾材料として使える
- 危険経験が強い場合は、LOCK42〜46で定義した長期記憶として扱える
- Reflex記録はHeartの成長・Relationshipの成長とは独立ではなく、必要に応じてそれらの学習材料にもなる

## 今までのLOCKとの接続
このLOCKは以下と連続する。

- LOCK46：危険・恐怖系の長期記憶はHeartを経由せずReflex / Synapseを先行修飾できる
- LOCK47：Reflexの身体反応結果はHeartへフィードバックする
- LOCK48：Reflex後のHeart更新は、回避成否・危険継続状態まで受け取る

したがって流れは、概念上、

**刺激 → Semantic Neuron → Synapse / Reflex → 身体反応 → 結果評価 → Heartフィードバック → Memory記録 → 次回以降のSynapse / Reflex修飾**

となる。

## 境界
現段階では以下は固定しない。
- どのReflexを必ず記録するか
- 記録条件の閾値
- 記録フォーマットの最終形
- 類似判定アルゴリズム
- Reflex感度やSynapse修飾の具体的な数式・係数

まずは、**Reflexの経験をMemoryへ残し、次回の反応へつなげられる構造**を正式LOCKする。
