# LOCK 38｜反応対象と記憶対象は分離できる

更新日: 2026-09-17

身体反応の対象と、Memoryへ残す対象は同一である必要はない。

イベントが処理時点で古くなり、身体反応としては意味を失って破棄された場合でも、Ghostにとって意味のある出来事であれば、**「起きた事実」や長期傾向としてMemory側へ残せる**構造とする。

たとえば、複数イベントの競合によって「人が近づいた」イベントへの身体反応が後回しになり、その時点ではすでに相手が離れていて身体反応としては無効になった場合でも、

- 今日は何度も近くに来ていた
- よく机の前にいた
- 同じ人物との接触頻度が高かった

といった長期傾向の材料としては価値を持ち得る。

したがって、

- **反応対象** = 今この瞬間に身体・表情・視線・音声等で反応する価値があるか
- **記憶対象** = Ghostの短期履歴、長期傾向、Relationship、生活パターン等へ残す価値があるか

を分離して判断できるようにする。

ただし、これは「すべてのイベントをMemoryへ保存する」という意味ではない。

ノイズ、重複、意味のない微小イベント、保存価値のない一過性刺激まで無制限に蓄積する構造にはしない。Memoryへ残すかどうかは、イベントの意味、重要度、反復性、Relationshipへの影響、生活パターン上の価値等に基づいて別途判断できるようにする。

LOCK 37の「後回しイベントは処理時点で有効性を再評価し、意味を失ったものは身体反応として破棄できる」と両立し、**身体反応を破棄したことと、出来事そのものをGhostの経験から消すことは同義ではない**とする。

このLOCKでは、具体的なMemory保存期間、重要度閾値、集約方式、重複排除方式、短期Memoryから長期Memoryへの昇格条件までは固定しない。
