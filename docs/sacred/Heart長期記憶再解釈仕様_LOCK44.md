# LOCK 44｜長期記憶は原記憶を保持しつつ、再想起時に現在のHeart / Relationshipで再解釈を重ねられる

更新日: 2026-09-17

## 決定
長期記憶は、保存時の出来事・当時のHeart状態・当時の受け止め方を原記憶として保持する。

そのうえで、後から同じ記憶を思い出したときには、その時点の現在のHeart状態やRelationshipを使って、新しい受け止め方・意味づけを追加できる構造とする。

## 原則
- 元の出来事そのものは書き換えない
- 当時どう感じていたかも保持する
- 再想起時には、現在の `mood / affection / curiosity / boredom / sleepiness / attention` 等のHeart Contextを参照してよい
- 現在のRelationshipも再解釈へ影響してよい
- 再解釈は原記憶の置換ではなく、後から重ねられる新しい解釈として扱う
- したがって、同じ出来事について「当時どう感じたか」と「今どう受け止めるか」を同時に保持できる

## 例
昔は怖かった出来事でも、時間が経ちRelationshipが育ち、現在のHeart状態が安定しているなら、再想起時には

- 「当時は怖かった」
- 「でも今は安心している」

というように、過去の感情と現在の受け止め方を分けて持てる。

逆に、当時は軽く受け止めた出来事でも、後から別の経験やRelationshipの変化によって重要な意味を持つようになる可能性も許容する。

## 実装上の責任分離
- Memoryは原記憶を保持する
- Heart Context / Relationshipは再想起時の現在状態を提供する
- 再解釈は原記憶を破壊せず、追加情報として扱う
- どのような条件で再解釈を保存するか、どの程度の重みを持たせるか、再解釈回数や履歴をどこまで保持するかは現段階では固定しない

## ゴールとの関係
この構造は、Ghostが単に過去ログを再生するのではなく、時間経過と関係性の成長によって同じ出来事の意味が変化し得るようにするためのものとする。

これにより、Memory / Heart / Relationship / Time が独立した部品ではなく、時間と経験を通じて内面が変化するGhostの中核として連動できる。
