# LOCK｜Ghost 学習能力（経験学習A・行動学習B拡張構造）

- 状態：LOCK
- 確定日：2026-10-21
- 対象：M5Stack Desktop Companion / M5Stack CoreS3 / Ghost
- 位置づけ：既存の設計思想・Ghost五中核を変更せず、学習機能を追加するための正式決定事項

## 1. 最上位原則

M5Stackを「机の上に常にいて、周囲を感じ、反応し、気分が変わり、少しずつ関係性が育つ相棒」として成立させる。LLMを心とせず、M5単体で生命活動と経験学習を継続できることを優先する。

## 2. 学習方針【LOCK】

**A：経験によって性格・反応傾向・行動傾向が少しずつ変化する学習をGhostへ組み込み、初期実装対象とする。**

**B：新しい仕草・反応パターンを習得する行動学習についても、将来実装できる構造を初期段階から用意する。** Bの具体的な学習アルゴリズムや行動レパートリーは未決定であり、現段階で実装完了とは扱わない。

## 3. Ghostとの関係【LOCK】

Ghostの既存五中核は **Heart / Memory / Time / Relationship / Behavior** のまま維持する。

Learningは第六の人格・独立した心ではなく、Memory・Relationshipに蓄積した経験をHeart・Behaviorの判断へ反映する**Ghost内部の横断的な学習機構**とする。

- Heart：一時的な気分・状態を扱う。
- Memory：経験および学習結果の保持に関与する。
- Time：経過時間・生活リズムを学習へ反映できる。
- Relationship：相手との接触経験に基づく関係性の変化を扱う。
- Behavior：学習した傾向を行動選択に反映する。
- Learning A：経験から反応・行動の傾向を更新する。
- Learning B：安全に許可された表情・動作要素の組合せ等による新しい行動の習得を可能にする拡張構造を持つ。

上記は責務の整理であり、具体的なクラス構成・保存形式・更新式の確定ではない。

## 4. 不変条件【LOCK】

1. **M5単体で成立**：Pi5、ネットワーク、LLMの稼働を学習の必須条件にしない。
2. **緩やかな変化**：一度の経験で性格・反応傾向が激変しないよう、変化量を制御する。
3. **学習結果の永続化**：電源断・再起動後も、経験から得た変化を保持できる。
4. **感情と学習結果の分離**：一時的な怒り・驚き等を再起動後までそのまま持ち越さず、学習した傾向は残せる。
5. **安全優先**：学習によって反射・安全制御・動作制限を上書きさせない。
6. **Bへの拡張性**：後でGhost全体を作り直さず、行動学習を実装できる構造とする。
7. **既存構造尊重**：Ghostを後で捨てる簡易版に置き換えない。Device → Adapter → Nerve Inputの意味化された入力を使う。

## 5. 学習例（仕様確定ではない）

- 撫でられた経験に応じ、安心しやすさが緩やかに変わる。
- 接触する時間帯の傾向を覚え、行動の選び方に反映する。
- 繰り返し経験した刺激への反応傾向が変わる。
- 将来、許可された動作・表情の組合せを新しい仕草として覚える。
