# LOCK 39｜Memoryは「出来事」と「その時どう感じたか」をセットで記録できる

更新日: 2026-09-17

## 決定
Memoryへ残す経験は、単なる出来事の事実だけではなく、必要に応じて**その出来事をGhostがその時どう受け止めたか**まで含めて記録できる構造とする。

単純な事実ログだけでは、Ghostの成長・Relationship変化・Heart平常値の長期変化につながる「経験」になりにくい。

したがって、Memory側では少なくとも以下を分離して保持できる構造を前提とする。

- **出来事そのもの**
  - 何が起きたか
  - 誰との出来事か
  - いつ起きたか
  - 必要に応じて継続時間や回数

- **その時の内面状態・受け止め方**
  - その時点のHeart Context
  - その出来事がHeartへ与えた主作用・副作用
  - その時のRelationshipとの組み合わせ
  - 必要に応じて「嬉しかった」「警戒した」「興味を持った」「眠くて反応が薄かった」等へつながる意味情報

## 例
同じ「撫でられた」という出来事でも、Memory上では単に

`撫でられた`

だけを保存するのではなく、必要に応じて、

- affectionが高い時に撫でられて嬉しく受け取った
- moodが低い時だったので反応は小さかった
- sleepinessが高く、身体反応は薄かった
- Relationshipがまだ浅く、好奇心と警戒が混ざった

など、**同じ出来事でもその時のGhostの状態によって違う経験として扱える**ようにする。

## 成長との関係
この構造により、長期的には

- Relationshipの変化
- Heart平常値の変化
- よくある出来事への慣れ
- 特定相手との経験の蓄積
- 同じ出来事でも過去と現在で受け止め方が変わること

を扱えるようになる。

つまりMemoryは「何が起きたか」だけを保存するログではなく、**Ghostがその出来事をどう経験したかを残す場所**として扱う。

## LOCK 38との関係
LOCK 38により、身体反応の対象と記憶対象は分離できる。

したがって、身体反応としては古くなって破棄されたイベントでも、Ghostの成長や長期傾向に意味がある場合は、Memoryへ経験として残してよい。

逆に、すべてのイベントを無条件に保存するわけではない。

## 今回は固定しない事項
以下は実装境界を越えるため、現段階ではLOCKしない。

- どのイベントを必ず保存するか
- 保存期間
- Short Memory / Long-term Memory間の昇格条件
- Heart Contextを全数値保存するか、要約して保存するか
- 感情ラベルの具体的な種類
- Memoryの圧縮方式
- 忘却アルゴリズム
- 重み付け係数

今回のLOCKは、**Memoryへ残す経験は「出来事」だけではなく、「その時どう感じたか・どう受け止めたか」までセットで持てる**という骨格を固定するものである。
