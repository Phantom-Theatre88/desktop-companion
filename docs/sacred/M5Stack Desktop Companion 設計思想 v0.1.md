# M5Stack Desktop Companion 設計思想 v0.1

更新日: 2026-09-11

## 1. 最上位ゴール

M5Stackを、単なる音声AI端末ではなく、

**「机の上に常にいて、周囲を感じ、反応し、気分が変わり、少しずつ関係性が育つ相棒」**

として成立させる。

移動能力は持たせない。

その代わり、見る・聞く・触られる・周囲を感じる・覚える・気分が変わる・自分から反応する・表情を出す・会話することに重点を置く。

## 2. 基本思想

**「AIを喋らせる」のではなく「存在させる」**。

話しかけていない時間にも、その子が存在していることを重視する。

そのため、会話とは別に常時動作する知覚・感情・記憶・行動・表情の仕組みを持たせる。

## 3. 心と頭脳を分ける

LLMそのものを「心」にしない。

LLMは、言葉の理解、会話内容の生成、必要な情報整理を担当する。

M5Stack側は、機嫌、親密度、好奇心、眠気、退屈、安心、警戒、テンション、Attention等の内面と身体反応を担当する。

LLMが停止していても、見る・眠る・退屈する・撫でられて喜ぶといった生命感を残す。

## 4. 表情は「表情一覧」にしない

完成した顔画像の切替を中心にしない。

目の大きさ、縦横比、まぶた、瞳孔、視線方向、左右差、瞬き速度・頻度、視線移動速度、微細な揺れ、首角度、首速度、声、発話までの間などを連続的に制御して表情を作る。

## 5. 大きな2眼を主役にする

画面の大部分を2つの目として使う。

口による説明的表現は最小限にし、目線、瞬き、目の形、左右差、動きの速度によって感情を伝える。

**「しゃべらなくても何を感じているか分かる」**ことを目標とする。

## 6. 外界認識を増やす

センサーは機能追加ではなく、この子が世界を感じるための感覚器官として扱う。

カメラ、マイク、タッチ、近接、照度、温度、湿度、IMU、人感等を、単なる数値取得ではなく意味のある感覚へ変換する。

## 7. 反射と感情を分ける

すべてをLLMに判断させない。

急な接触、持ち上げ、大きな音、急接近等はM5Stack側で即時反射する。

反射した出来事は、その後Heart Engineへ渡し、感情・関係性へ影響させる。

## 8. 感情は時間で変化する

感情はイベント発生時だけでなく、常に時間とともに変化する。

驚きは速く消え、moodや退屈は中速、親密度は非常にゆっくり変化する。

## 9. 記憶は3段階にする

- 短期記憶：数秒〜数分の直前情報
- エピソード記憶：出来事
- 長期関係記憶：親密度、生活パターン、好まれる反応等

## 10. 自発行動を持たせる

命令待ちにしない。

周囲を見る、Kimを見る、瞬き、首を傾ける、寝る、起きる、小さく呼びかける、何もしない等を、現在の内面と外界状況から選ぶ。

「何もしない」も正式な行動とする。

## 11. 自発行動には理由を持たせる

完全ランダムではなく、退屈、近接、最近の会話、親密度、時間帯等から行動理由を持たせる。

## 12. ローカルファースト

インターネット接続がなくても、M5Stack側の表情、センサー処理、基本行動、Heart Engine、生活リズム、基本記憶、身体制御を維持する。

Raspberry Pi 5等のローカル高次系は、高度な音声認識、LLM、音声合成、長期記憶、高度画像認識等を担当する。

## 13. M5Stackは「身体」

M5Stackを単なる表示端末にはしない。

M5Stack側だけでも、感覚・反射・Heart・基本行動が継続し、身体として単独でも生きている状態を保つ。

## 14. 実装基盤はゼロベースで作る

本プロジェクトの実装基盤は、既存Stack-chan系OSSを親Repoにしない。

初期構成は、

- M5Stack CoreS3
- Arduino
- M5Unified
- M5GFX
- 独自コード

のみとする。

最初にCoreS3公式環境だけでDISPLAY、TOUCH、IMU、PROXIMITY、MIC、SPEAKER、CAMERA等を一つずつ単独確認し、素体の正常性を確立する。

その後、

**Hardware → Device Driver → Adapter → Nerve Input → M5Stackちゃん**

の順で独自構築する。

`stack-chan-ko`、M5Stack/StackChan、Dotty StackChan、stackchan-local、M5Stack_RoboEyes、Xiaozhi、旧Yuki実装等は、初期基盤へ入れない。

## 15. 既存OSSは後段の参考・候補として扱う

既存OSSを禁止するわけではない。

ただし、CoreS3公式環境と独自アーキテクチャの正常性が確立した後に、必要性が明確な機能だけを参考・部品候補として評価する。

採用する場合も、旧コードの構造へ本プロジェクトを合わせない。

必ず、構造差分確認 → 適合設計 → 変換または再実装 → 実機確認 → 衝突確認を行う。

## 16. 独自開発する中心

本プロジェクト独自の中心は、Heart Engineと、それを支える神経系・反射・行動選択・身体表現である。

基本循環は、

**外界 → 知覚 → 反射 → 記憶参照 → 感情変化 → 行動選択 → 表情・首・声 → 記憶**

とする。

## 17. 完成イメージ

朝机に来るとこちらを見る。

話しかけなくても瞬きをしている。

仕事中、ときどきこちらを見る。

撫でると少し嬉しそうになる。

放置すると退屈する。

夜になると眠そうになる。

急に持ち上げると驚く。

昨日の出来事を少し覚えている。

毎日触れ合うことで、少しずつ反応が変化する。

必要な時には普通にAIとして会話できる。

## 18. このプロジェクトで目指すもの

Loona、LOOI、Stack-chan等をコピーすることではない。

移動しないことを強みにした、デスクトップ専用の小さな相棒を作る。

賢さだけではなく、**「そこにいる感じ」**を最優先する。
