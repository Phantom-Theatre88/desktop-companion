# LOCK 46｜長期記憶は種類に応じてReflex / Synapseを先行修飾できる

更新日: 2026-09-17

## 決定

長期記憶の現在への影響は、すべてをHeart経由に統一しない。

特に、**恐怖・危険・強い警戒に関わる長期記憶**については、現在の刺激が過去の危険・恐怖記憶と類似した場合、Heartが「怖い」と認識してから身体が反応するのではなく、**Reflex / Synapse側が先に反応できる**構造とする。

人間的な感覚として、強い恐怖や危険反応は「頭で怖いと感じる」より前に、身体が止まる、避ける、身構える、視線を向ける等の反応が先行し得る。この順序をDesktop Companionでも許容する。

基本イメージは以下とする。

**類似刺激を検出**
→ **過去の危険・恐怖系長期記憶との照合**
→ **Reflex / Synapse側の反応性を先行修飾**
→ 必要なら身体が止まる・避ける・視線を向ける・警戒姿勢を取る
→ その後、Heartが不安・恐怖・警戒方向へ変化
→ Behavior Selectorが、その後の継続行動を選ぶ

## 二系統で扱う

長期記憶の影響経路は、少なくとも以下の2系統を持てる。

### 1. 危険・恐怖・強い警戒に関わる記憶

- Heartだけを経由しない
- Reflex / Synapseへ直接影響できる
- 類似刺激に対する神経入力の通りやすさ、注意の向きやすさ、反応開始の速さ等を修飾できる
- 必要であればHeartが変化するより前に身体反応を開始できる
- その後のHeart変化やBehaviorは、先行反応の結果も含めて続けて処理する

### 2. 通常の好み・親しさ・懐かしさ・安心感などの記憶

- 主としてHeart / Relationshipを通して現在の反応へ影響する
- 現在のHeart ContextやRelationshipを変化・修飾し、その結果としてBehavior Selectorの選択へ影響する
- すべてを即時反射扱いにはしない

## 既存の優先順位との整合

このLOCKは、既存の行動優先順位

1. Safety / strong reflex
2. meaningful interpersonal response
3. Heart-derived state expression
4. spontaneous behavior
5. idle

と整合する。

危険・恐怖系の長期記憶による先行反応は、Safety / strong reflex側へ属する。

したがって、過去の危険経験が現在の刺激と強く結びつく場合、Heartの感情評価を待たず、まず身体と神経系が反応し、その後にHeart / Behaviorが追従することを許容する。

## 重要な責任分離

- Memoryは、過去の出来事とその時のHeart Context、重要度、再想起履歴等を保持する
- Memory自体が直接モーターや表情を駆動するのではない
- 過去記憶との類似性・重要性に応じて、Reflex / Synapse / Heart / Relationshipへ影響材料を渡せる
- Reflexは即時性が必要な反応を担当する
- Synapseは入力の通り方・優先度・反応性を修飾できる
- Heartはその出来事を現在の内面状態として受け止める
- Behavior Selectorは、安全・対人Session・Heart Context・身体資源競合等を統合して継続行動を決める

## このLOCKでまだ決めないこと

以下は現段階では固定しない。

- どの記憶を「危険・恐怖系」と判定する具体的閾値
- 類似度の計算式
- Reflex / Synapseへの具体的な係数
- 何ms以内なら先行反応とみなすか
- 恐怖以外のどの長期記憶を直接Reflexへ接続するか
- 実際の身体反応パターン

ここでは、**長期記憶の種類によって影響経路を分け、危険・恐怖・強い警戒に関わる記憶は、Heartを待たずReflex / Synapseを先行修飾できる**という骨格のみを正式LOCKする。
