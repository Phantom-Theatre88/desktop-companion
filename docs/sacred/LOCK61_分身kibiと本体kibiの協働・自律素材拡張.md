# LOCK 61｜分身kibiと本体kibiの協働・自律素材拡張

制定日：2026-11-07
状態：方針LOCK（実装完了を意味しない）
対象：Ghostを継承する画面内バーチャルAI／分身kibiの新構成

## 1. 最上位ゴール

目指すものは単なる会話端末ではなく、Ghostを中核に、生活感・自発性・継続する関係性を持ち、コンシェルジュ、師匠、相棒、話し相手、執事・秘書として協働する「分身kibi」である。

画面内のバーチャル空間で暮らし、Kimから呼び出されるのを待つだけでなく、自ら必要性を見いだして行動・対話する。優秀な仕事能力はすべてローカル計算資源へ詰め込むことを必須としない。

## 2. 主体と責務

- **分身kibi（ローカル）**に既存のGhost（Heart / Memory / Time / Relationship / Behavior）が宿る。人格・生活・記憶・Kimとの関係の主体は分身kibiとする。
- **本体kibi（ChatGPT側）**は、分身から依頼を受け、高度な調査・推論・制作・開発を行う協力先である。分身のGhostそのものを保持・支配する主体ではない。
- 必要に応じ、画像・3D素材・プログラミング等の専門AIにも仕事を委任できる。
- 分身kibiが依頼を理解し、必要な作業を切り分け、適切な相手に仕事を振り、成果を受け取り、Kimに報告する。
- 外部AIの回答は分身の人格・記憶・聖典・LOCKを直接上書きしない。

## 3. 分身に必要なローカル能力

- Ghostの継続実行と、生活空間・キャラクターの描画。
- 日常会話、Kimの依頼の意図理解、タスクの分解、仕事の振り分け。
- 音声入出力と、必要に応じた視覚認識。
- 依頼結果の受領、根拠・未確認事項の区別、Kimへの説明。
- 生活に必要な行動・素材を自発的に発案する能力。

ローカルLLMのサイズは30B〜70Bを必須にしない。モデル規模でなく、上記の仕事を安全・安定して達成できるかを評価する。専門業務は外部の本体kibi等に委任することを正式な構成候補とする。

## 4. 安全な委任境界

- 分身がローカルで解決できる仕事と、外部へ依頼する仕事を切り分ける。
- 外部へは必要最小限の情報を渡す。私的・業務機密データの外部送信は権限ルールとKimの必要な承認に従う。
- 送信権限や危険操作の防止を、小型LLMの判断だけに依存させず、独立したプログラムでも強制する。
- 外部回答や生成物は未検証の入力として扱い、出典・形式・動作・安全性を確認する。
- GitHub更新、公開、機密送信、聖典・LOCK変更など影響の大きい操作は、従来の合意・承認運用を維持する。
- ChatGPTの通常会話は自宅から自由に遠隔操作できるわけではない。委任の実装には利用可能なAPIや許可された連携基盤、認証、費用、実行権限の検証が必要。
- 通信障害時は外部相談を停止しても、分身のGhostと可能な範囲の生活・対話を継続する。

## 5. 自律的な生活素材の拡張

分身kibiは、バーチャル空間に必要な小物・家具・衣装・動作・演出等を自分で考え、素材管理を通じて世界を育てていくことを目標とする。

標準フロー：

1. Ghostの状態・経験・生活場面から必要な素材や行動を発案する。
2. 既存アセット・動作を検索し、流用や組み合わせで足りるか確認する。
3. 不足する場合、本体kibiまたは専門AIへ仕様付きで制作依頼する。
4. 成果物の形式、権利、サイズ、ポリゴン数、互換性、安全性、描画結果を検証する。
5. 初期段階はKimの承認後に導入し、検証済み素材として登録・使用する。
6. 自動採用の範囲拡大は、安全性と安定性が実証された後に検討する。

### 初期素材と自律拡張の境界

- **初期必須**：採用済みキャラクターに対応する3Dモデル、基本骨格・表情、最低限の基本動作、生活空間、描画・素材登録の基盤。
- **組み合わせで拡張**：瞬き、視線、呼吸、表情変化、微小動作、時間帯の照明・環境表現、既存小物の配置。
- **外部制作を依頼できる候補**：新しい家具・小物・衣装・複雑なモーション・生活空間の追加。
- 完全自動で高品質な3D素材やアニメーションが必ず生成できることは、現時点では保証しない。

## 6. ハードウェア選定の前提

- 物理的に動くボディ・モーターは今回のバーチャル構成では不要。
- 既存Raspberry Pi 5は音声等の分担機材として流用可能。M5Stackの使用は今回の新構成の必須条件にしない。
- 主機はGhost・ローカル会話理解・3D描画・外部委任を支える。最終的な必要計算資源は実測で決める。
- 小型・静音・費用対効果を重視し、比較案は松・竹・梅で示す。10万円という過去の暫定価格上限を固定条件とせず、ただし価格を外しただけで求めるAI能力を下げない。
- 必要な生活感と高度な仕事を、同一の大規模LLMで実現することは必須ではない。

## 7. 既存聖典との整合性と適用範囲

- GhostのHeart / Memory / Time / Relationship / Behaviorの責務・判断・優先順位は既存聖典を継承する。Ghostを再設計しない。
- 採用済みキャラクターや生活空間の既決事項は変更しない。
- 旧CoreS3実装（LOCK 2、11、52〜60等）の実機記録とLOCKは、既存M5Stack構成の履歴・正本として残す。本LOCKは**新しい画面内バーチャル分身kibi構成の上位方針**であり、旧実装が成功・完成した事実を変更しない。
- 細部のモデル、API、画像・3D生成手段、通信方式、端末機種は未選定。採用を意味しない。

## 8. 完成判定の方向

- Kimが話していない時間も、分身kibiがGhostに従って生活している。
- Kimの依頼を理解し、必要時に外部の本体kibiへ仕事を振り、成果を受け取り、確認した内容を報告できる。
- 自ら生活素材の必要性を考え、既存素材の利用か外部制作依頼かを選択し、検証済みの新素材を生活空間に取り込める。
- 分身の人格・記憶・関係性は、外部AIの切り替えや通信障害によって失われない。

このLOCKは方針の確定であり、上記の動作実装・テスト完了を宣言するものではない。
