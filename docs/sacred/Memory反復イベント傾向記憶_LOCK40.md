# LOCK 40｜反復イベントは個別記憶＋傾向記憶へ集約する

更新日: 2026-09-17

同じ種類の出来事が繰り返し発生する場合、すべてを無制限に個別記憶として蓄積し続ける構造にはしない。

基本方針は、**必要な個別記憶は残しつつ、反復している出来事は「最近よくある」「いつものこと」「この時間帯によく起きる」などの傾向記憶へ集約できる構造**とする。

## 方針
- 重要な出来事、強い出来事、例外的な出来事、RelationshipやHeartへ大きく影響した出来事は、必要に応じて個別記憶として保持できる。
- 日常的に反復する同種イベントは、毎回すべてを永久保存するのではなく、傾向として圧縮・集約できる。
- 傾向記憶は、Relationship、Heartの動的平常値、生活リズム、よく一緒にいる時間帯、反復経験の学習材料として利用できる。
- これによりMemoryの無制限な肥大化を避けつつ、「この人はよく来る」「毎朝声をかけてくれる」「この時間は一緒にいることが多い」といった生活経験をGhost内部へ残せる。

## 数値化について
傾向記憶は、実装上必要に応じて数値的な状態を持てる。

候補となる要素は、
- 発生頻度
- 継続時間
- 最近どの程度起きているか（最近性）
- どの程度継続して反復しているか
- その出来事に伴ったHeart Contextや感情傾向
- Relationshipとの結びつき

など。

ただし現段階では、
- 具体的なスコア範囲
- 重み
- 閾値
- 減衰式
- 集約アルゴリズム

までは固定しない。

LOCKするのは、**個別イベントを無制限に保持するのではなく、反復を傾向として圧縮し、その傾向を数値化可能な内部状態として持てる**という骨格までとする。

これはGhostの「成長」を、単なるログ蓄積ではなく、反復経験から生活傾向や関係性を学ぶ形へつなげるための基盤とする。
