# LOCK 45｜強い長期記憶は、類似イベント時に現在のHeart / Behaviorへ自動的に影響できる

更新日: 2026-09-17

## 決定
長期記憶は、明示的に「思い出す」処理を行った時だけ現在へ影響するものとはしない。

過去の強い記憶と類似する出来事が現在起きた場合、Memory側はその関連性を検出し、現在のHeart ContextやBehavior Selectorへ自動的に影響を与えられる構造とする。

## 意図
たとえば、過去に非常に怖かった刺激に似た出来事が再び起きた場合、毎回明示的な想起命令を経由しなくても、警戒や反応の強まりが自然に現れるようにする。

逆に、過去に強く安心・好意・嬉しさと結びついた出来事と似た状況では、現在のHeartやBehaviorに好意的な影響が出てもよい。

この構造により、Ghostは単に「記憶を保存している」だけではなく、過去の経験が現在の反応性に反映される。

## 原則
- 長期記憶の影響は、Memoryが身体動作を直接命令する形にはしない
- Memoryは、類似記憶の存在・想起強度・関連する当時のHeart Context・現在の再解釈等を、現在のHeart / Synapse / Behavior Selectorが参照できる形で渡す
- 最終的な身体表現はBehavior Selectorが決定する
- 安全系の強反射がある場合は、既存の優先順位どおり安全を最優先する
- 類似性の具体的な計算方式、しきい値、重み、減衰係数は現段階では固定しない

## LOCK 44との関係
LOCK 44で、長期記憶は原記憶を保持しつつ、再想起時に現在のHeart / Relationshipで新しい解釈を重ねられるとした。

LOCK 45では、その記憶が現在の出来事と十分に関連する場合、明示的な手動想起がなくても現在のHeartやBehaviorへ影響できることを追加で固定する。

## 実装上の境界
現段階では、以下まではLOCKしない。
- どの程度似ていれば自動影響を発生させるか
- 影響量の具体的な数値
- どのHeart項目へ何％反映するか
- 類似検索アルゴリズム
- Pi5側で行うかM5側で行うかの最終分担

まずは、**「強い長期記憶は、似た出来事が起きた時に自動的に現在のHeart / Behaviorへ影響できる」**という骨格のみを正式LOCKする。
