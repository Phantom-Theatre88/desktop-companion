## 1. WORLDの存在理由【LOCK】

**WORLDは、AKARIが未知に出会い、自分の意図に反する出来事も経験し、その経験を蓄積するための、第三者による自律的な世界生成・管理システムである。**

- WORLDは「神の目」に相当し、世界全体の状態・物理法則・時間・環境・出来事・因果関係を把握・管理する。
- WORLDはGhostの心やBrainの思考に依存せず、自身の法則と継続する状態に従い環境を進行させる。
- WORLDをGhostの下請けの背景生成機能としない。Ghostに世界全体の生成・管理負荷を負わせない。
- WORLDが生成する未知や将来の出来事を、Ghostへ全知情報として事前提供しない。
- AKARIが経験する驚き、成功、失敗、発見が成立する世界を目指す。

## 2. 介入権限と不可侵性【LOCK】

- **通常運転中、Brain・Ghost・NERVA・CharacterがWORLDの真の内部状態、世界法則、未来の出来事を都合よく直接書き換えることを禁止する。**
- Ghostの「こうなってほしい」という欲求は、WORLDへの直接改変命令ではない。
- Ghostの自発的な行動意図に基づき、NERVAが身体を動かし、WORLDがその行為と世界の法則から結果を判定する。
- AKARIが物を動かす・作る・環境へ働きかけることは許容する。ただし**行為に対する結果はWORLDが決定**し、成功は保証されない。
- 「誰も関与できない」とは**恣意的な内部改変を許さない**ことであり、世界への物理的・因果的な働きかけまで禁止する意味ではない。
- Kimによる設定変更、停止、バックアップ、復旧、検証などの**管理者権限・安全機能は除外せず確保する**。その具体方式は未決定。

## 3. 知識の非対称性【LOCK】

- WORLDは世界全体の状態を管理する「神の目」を持つ。
- GhostとAKARIが取得する情報は、原則として実際に知覚・観測・経験できた範囲に制限する。
- 未知の場所・物・変化・イベントの内部情報を、観測前にGhostへ漏らさない。
- 予測不能性は無秩序ではなく、世界法則・継続性・因果関係のもとで成立させる。
- WORLDはGhostの知らないところでも時間と環境の状態を進行させ、出来事の結果を永続化する。

## 4. 相互作用の責務境界【LOCK】

| 対象 | 担当 |
| --- | --- |
| **WORLD** | 世界の生成・保存・時間経過・天候等の環境変化・物理法則・出来事・行動結果の判定 |
| **Ghost** | 自身の感情・欲求・記憶・関係・自発的判断・身体表現意図。観測された出来事を経験として記憶 |
| **NERVA** | Ghostからの行動意図を具体的な連続動作に変換。モーション番号や保存済みシーンを再生する方式を基本にしない |
| **Character** | AKARIの3D身体を表示し、WORLD内の実際の身体状態を表現 |
| **Brain** | 会話・推論・作業・知識。WORLDの内部状態を恣意的に変更する権限は持たない |

**一例（概念的な流れ）**：Ghostがコップを持ちたいと判断 → NERVAが動作を生成 → WORLDが接触・重力・物体状態を判定 → AKARIが結果を観測 → Ghostが経験として記憶。

## 5. 自発的な出来事と世界の継続性【LOCK】

- KimやGhostが命令しない間も、WORLD側で出来事が発生・進行しうる。
- 世界の物体配置や変化した状態は保存し、翌日にも因果的に引き継ぐ。
- AKARIに知らないこと、予期しないこと、失敗することが存在する。
- WORLDはAKARIの感情に合わせて世界を常に好都合に変形させない。
