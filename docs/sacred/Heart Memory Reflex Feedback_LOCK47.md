# LOCK 47｜Reflexの身体反応結果はHeartへフィードバックする

更新日: 2026-09-17

## 決定
危険・恐怖・強い警戒に関わる刺激では、長期記憶やSynapse修飾によりReflexがHeartより先に身体反応を起こしてよい。

その場合、Reflexは身体反応だけで完結させず、**「どのような反射が起きたか」という結果をHeartへフィードバックする**。

## 基本の流れ

**類似刺激を検出**
→ **Synapse / Reflex側で先行反応**
→ **身体が止まる・避ける・視線を向ける等の反射行動**
→ **その反射結果をHeartへ返す**
→ **Heartが現在の内面状態へ反映する**
→ **その後のBehaviorへつながる**

## Heartへの反映
Reflexから返された結果は、必要に応じて `attention`、`mood`、`curiosity`、その他現在のHeart状態へ影響してよい。

例：
- 急な刺激に対して身体が先に止まった
- その結果、Heart側で `attention` が上がる
- `mood` が警戒・不安方向へ変化する場合がある
- その後のBehavior Selectorは、更新後のHeart Contextと現在の外界状況を見て次の行動を選ぶ

## 責任分離
- Reflexは、危険や強い刺激に対する即時的・身体的な先行反応を担当する
- Heartは、その反射が起きたという事実と反応結果を内面状態へ取り込む
- Behavior Selectorは、反射後のHeart Contextと外界状態を見て、その後の継続行動を選ぶ

Reflexが直接Heart内部値を書き換える構造にはしない。
Reflexは**反射結果をSemantic /共通イベントとしてHeartへ返し、Heart Engine自身が内部状態を更新する**責任分離を維持する。

## このLOCKの意図
これは、

**「頭で怖いと判断してから体が動く」のではなく、体が先に反応し、その反応結果を内面が受け取る**

という順序を実装上も許容するためのLOCKである。

これにより、LOCK 46で定めた「恐怖・危険系の長期記憶はReflex / Synapseを先行修飾できる」という構造と、Heart / Behaviorの後続処理を接続する。

## 今は固定しないもの
- Reflex結果イベントの具体的な名前
- Heart各項目への具体的な変化量
- 反射結果の強度係数
- どの反射をどのHeart項目へ結びつけるかの全対応表
- タイミングのミリ秒単位の仕様

これらは実装・調整段階で決める。
