# LOCK 43｜長期記憶は時間経過で想起されにくくなるが、強い記憶・再想起された記憶は残りやすい

更新日: 2026-09-17

## 決定
長期記憶は、保存した時点の強さや影響を永久に固定するのではなく、時間経過によって徐々に「想起されやすさ」「現在行動への影響力」が弱まる構造とする。

ただし、ここでいう「薄れる」は、記憶データそのものを時間経過で物理削除することと同義ではない。

## 基本方針
- 長期記憶の本体データは保持できる
- 時間経過により、その記憶が自発的に呼び出される確率・優先度・現在のHeart/Behaviorへの影響度は低下し得る
- 強い出来事として保存された記憶は、通常の記憶より弱まりにくくできる
- 後から何度も思い出された記憶、同種の出来事で再活性化された記憶は、再び想起されやすく・影響しやすくできる
- 長期間使われない記憶は普段の反応からは出にくくなるが、関連する人物・状況・出来事・時間帯などをきっかけに再び呼び出せる余地を残す

## 実装上の考え方
長期記憶データそのものを毎秒・毎分書き換えて減衰させる方式を前提にしない。

各長期記憶について、たとえば以下のような情報を保持し、必要な時点で現在の「残りやすさ」「想起されやすさ」「影響力」を算出できる構造を許容する。

- 元の出来事の重要度
- 出来事の強度
- 保存時のHeart Context
- Relationshipへの影響度
- 発生日時
- 最後に想起された日時
- 想起回数
- 再活性化された回数
- 関連する人物・状況・文脈

この構造により、記憶本体を削除しなくても、時間と経験によって「普段は出てこない記憶」「今も強く残っている記憶」を表現できる。

## Ghostとしての意味
GhostのMemoryは、単なる永続ログではなく、時間と経験によって重みが変わる。

たとえば、
- 昔の出来事は少しずつ日常反応へ出にくくなる
- とても嬉しかった／怖かった／大切だった出来事は長く残る
- 久しぶりの再会など、似た状況が起きると古い記憶が再び表面化する
- 何度も思い出された出来事は、そのGhostにとって重要な記憶として残りやすくなる

という状態を作れる。

## 境界
現段階では以下は固定しない。
- 具体的な減衰率
- 時間単位ごとの係数
- 想起回数による強化量
- 記憶ごとの半減期
- 削除条件
- 再活性化の具体的な閾値
- 最終的な計算式

まずは、**長期記憶も時間によって現在への影響は薄れ得る。ただし強い記憶・再想起された記憶は残りやすく、記憶データそのものを即座に消す設計にはしない**という骨格をLOCKする。

このLOCKは、傾向記憶の減衰とは別に、特別な個別長期記憶が時間と再想起によって扱いを変えるための基本原則である。
