# LOCK｜Ghost 経験・記憶・解釈・時間による成長（2026-10-21）

- 状態：LOCK（設計合意。実装完了を意味しない）
- 対象：M5Stack Desktop Companion / CoreS3 / Ghost
- 位置づけ：既存の五中核、学習A/B、Mood/Comfort/SocialのLOCKを維持し、今回の対話で確定した原則を追記する。
- 優先関係：既存聖典の「再起動で一時感情をリセット」と読める表現については、本書の**経過時間による回復**を新しい解釈・決定とする。既存ファイル自体は変更しない。

## 1. 内部状態と平常心【LOCK】
1. 外部刺激がなくても、Heartの内部状態は相互に影響し、変化し続ける。過去の経験・時間帯・生活リズムも影響し得る。
2. 複数の感情・欲求は矛盾したまま共存できる。単純な勝敗・相殺だけで反応を一意に決めない。「怖いが気になる」も成立する。
3. 一時的な状態には平常へ向かう回復があるが、全状態が同じ速度で戻る必要はない。静かに過ごすことも自然な状態である。
4. 平常心の基準・反応傾向は、長期的経験によって**徐々に育つ**。一度の経験で性格全体を極端に変えない。

## 2. 電源と経過時間【LOCK】
1. 電源OFF/ON・再起動**そのもの**を一時感情のリセット条件としない。回復の判断基準は実際の**経過時間**とする。
2. 電源断中の経過時間も、復帰時に可能な範囲で考慮する。短時間の再起動では感情の余韻が残り得る一方、長時間経過後は平常に近づき得る。
3. 長期学習結果は電源断後も保持する。
4. 電源断中の時刻・経過時間をどう確実に取得するか、取得できない場合の扱い、状態保存形式は未決定。時計・永続化の実装を確認してから設計する。

## 3. 経験の強さと学習【LOCK】
1. 経験の重みは、回数・強度・状況・相手との関係などを総合的に考慮する。
2. **強い経験はその瞬間の強い反応を生む。** 反応の強さと、長期的な性格変化の大きさは区別する。
3. 強い一回の経験も重要な長期記憶になり得て、将来の類似状況での反応に影響し得る。ただし性格全体を一度で激変させない。
4. 警戒などの一時的な影響は、経過時間とその後の経験の両方で変化する。経験自体が残っていても警戒は和らぎ得る。
5. 再度似た刺激を受けたときの反応は、過去の経験により強まる場合も穏やかになる場合もあり、固定方向に決めない。

## 4. 相手・状況・理由の推測【LOCK】
1. 反応は「何をされたか」だけでなく、「誰にされたか」「その場の状況」も考慮する。
2. Ghostは「なぜそれをされたか」を**推測しようとする**。相手の意図を直接知ったと扱わず、根拠が足りなければ**理由不明**を許容する。
3. 同じ行為でも相手への信頼・状況・過去の経験で、その後の警戒や安心への戻り方が異なり得る。
4. 危険への反射・安全制御は理由の推測より優先する。

## 5. 記憶の事実・感情・解釈【LOCK】
1. **後から理解が変わっても、経験した出来事と当時の感情を「なかったこと」にしない。**
2. 出来事・当時の感情・当初の推測・後から追加された解釈を区別する。解釈はさらに修正・追加できる。
3. 後から「助けてもらったのかもしれない」と理解しても、当時「怖かった」という経験を消去・上書きしない。
4. 記憶は単なる保存履歴に留めず、必要な状況で**思い出して現在の判断に利用できる**ことを目指す。

## 6. 忘却と長期記憶【LOCK】
1. すべての出来事の詳細を永久保存する必要はない。
2. 日常的な反復経験は、学んだ傾向として蓄積できる。
3. 特に印象的な出来事は個別の思い出として保持し得る。
4. **出来事の詳細を忘れても、そこから学んだことは残り得る。** 記憶の詳細の保持と学習結果の保持は区別する。

## 8. 五中核への位置づけ（責務の整理）
- Heart：現在の状態、状態間の相互作用、経験により育つ平常傾向。
- Memory：経験、当時の感情、解釈の追記、重要な思い出、忘却と想起。
- Time：実経過時間、時間帯・生活リズムとの関係。
- Relationship：相手ごとの経験、信頼・関係性の変化。
- Behavior：現在の状態・経験・関係・状況を踏まえた反応選択。
- Learning A：上記五中核を横断し、経験による反応傾向の変化を担う。第六の中核ではない。
