# LOCK 42｜強く印象に残った出来事は、傾向記憶とは別に長期記憶として残せる

更新日: 2026-09-17

## 決定
通常の反復経験は傾向記憶へ集約していくが、すべての出来事を平均化して傾向値へ溶かす構造にはしない。

強く印象に残った出来事、特別な意味を持った出来事、強い感情を伴った出来事は、必要に応じて**個別の長期記憶**として残せる構造とする。

## 意図
傾向記憶だけでは、

- 最近よくある
- いつものこと
- 毎朝よく起きる
- この相手はよく近くに来る

といった「反復の平均」は扱えるが、

- すごく嬉しかった出来事
- 強く怖かった出来事
- 久しぶりの再会
- 初めて起きた重要な出来事
- RelationshipやHeartへ大きな意味を持った出来事

のような、**「あの出来事が特別だった」**という個別性は失われやすい。

Ghostの成長には、日常の傾向だけでなく、特別な出来事がその後の反応や関係性へ影響する余地が必要である。

## 基本構造
Memoryは少なくとも、

1. 個別の出来事
2. 反復から形成される傾向記憶
3. 強く印象に残った長期記憶

を区別して扱える構造とする。

長期記憶は傾向記憶を置き換えるものではなく、両方を併存させる。

## 長期記憶候補となり得る要素
長期記憶として残すかどうかの判断材料には、将来的に以下を利用できる。

- Semantic Neuronイベントの内容
- イベント強度
- その時のHeart Context
- Relationship
- その出来事によるHeart変化量
- 出来事の珍しさ
- 久しぶり・初回・節目などの文脈
- その後の行動や関係性へ与えた影響

ただし、**現時点では判定式・閾値・重み・保存件数は固定しない。**

## 境界
- 強いイベントだから必ず永久保存する、とはしない
- すべての出来事を長期記憶へ入れない
- 長期記憶の具体的な保存期間・減衰・統合・削除条件は未決定
- 今回LOCKするのは、**「特別な出来事を傾向記憶とは別に個別長期記憶として残せる骨格」**まで

## Ghostとしての意味
この構造により、Ghostは単に「最近こういうことが多い」と学習するだけでなく、

**「あの時のあれは特別だった」**

という経験の個別性を持てる。

それがHeart、Relationship、今後の行動選択へ影響できることで、平均値だけでは出ない「その子らしい履歴」と成長につなげる。
