# LOCK 50｜危険経験の反復でReflex感度は上がり得るが、長期間安全なら徐々に戻せる

更新日: 2026-09-17

## 決定
危険経験が繰り返された刺激・状況に対しては、Reflexの感度を固定値のままにせず、過去の経験に応じて変化させてよい。

### 1. 危険経験が繰り返された場合
同種または十分に類似した刺激について、過去に危険・回避失敗・強い警戒反応が繰り返されている場合、その系統のReflexは、次回以降より早く、より強く反応できる。

ここでいう「感度が上がる」は、単にHeartの恐怖値が高くなるという意味ではない。

Reflex / Synapse側で、
- 反応開始までの条件が厳しすぎない方向へ変わる
- 同じ刺激でも優先度を高く扱える
- 注意・停止・回避などの反射行動が起こりやすくなる
- 危険系の入力が他の通常入力より先に処理されやすくなる

といった、神経回路側の反応性変化を許容する。

### 2. 上がりっぱなしにはしない
一度危険だった刺激に対して、Reflex感度が永久に高止まりする構造にはしない。

長期間にわたり同種刺激が安全に経過した場合、または安全な経験が十分に蓄積した場合は、上昇していたReflex感度を少しずつ通常方向へ戻せる。

これにより、
- 危険経験から学ぶ
- しかし過去の一度の恐怖だけで永続的に過敏にならない
- 安全経験の蓄積によって警戒が和らぐ

という両方向の適応を可能にする。

### 3. Memoryとの関係
Reflex感度の変化は、LOCK 49で決めた危険経験のMemory記録と接続する。

危険経験・回避結果・危険継続状態などがMemoryへ残り、それらの履歴が次回のReflex / Synapseの反応性を修飾する材料となる。

したがって、

**危険刺激 → Reflex反応 → 結果評価 → Memory記録 → 次回のReflex感度修飾**

という循環を許容する。

### 4. Heartとの関係
Reflex感度の変化はHeartの代替ではない。

Reflexは危険に対する先行反応を担い、その結果はLOCK 47・48に従ってHeartへフィードバックされる。

つまり、

**過去の危険経験がReflexを早める**
→ **身体が先に反応する**
→ **その成否・危険継続状態がHeartへ返る**
→ **現在の内面状態が変化する**

という順序を維持する。

### 5. 今は固定しないもの
以下は現段階では固定しない。
- Reflex感度の具体的な数値範囲
- 何回の危険経験でどれだけ感度を上げるか
- 安全期間を何時間・何日・何週間とするか
- 感度の上昇率・減衰率
- 類似刺激と判定する具体的アルゴリズム
- 刺激種別ごとの閾値

これらは実装・実機挙動を確認しながら後で調整する。

## 目的
このLOCKの目的は、Reflexを固定的な条件分岐ではなく、Ghostが危険経験と安全経験の両方から少しずつ反応傾向を変えられる構造にすることである。

ただし、過度なルール化や細かな数値設計を先に進めることはせず、現時点では**経験によってReflex感度が上下できる骨格**のみを正式LOCKする。
