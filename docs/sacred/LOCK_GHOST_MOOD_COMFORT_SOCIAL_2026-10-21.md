# LOCK — Ghost 内部状態の独立性・相互作用と経験に基づく反応（2026-10-21）

## 決定事項
1. Ghost の最上位構造は **Heart / Memory / Time / Relationship / Behavior** の5要素を維持する。新たな第6要素を設けない。
2. **Mood（気分）と Comfort（安心感）は別々の内部状態**として扱う。
   - Mood：現在の快・不快の状態。
   - Comfort：現在の安心・警戒の状態。対人関係だけでなく周囲の環境に対する安心感を含む。
3. Mood と Comfort は、周囲からの刺激にそれぞれ反応して変化し、相互に影響する。ただし必ず同じ方向・同じ速度で変化するわけではない。
4. **Social（交流欲求）と Affection（愛着）も別の概念**とする。交流したい気持ちと、特定の相手への愛着は独立して変化し、互いに影響し得る。
5. Ghost は同じ刺激に対しても、現在の Heart の内部状態、Memory の経験、Time、Relationship を踏まえ、Behavior から異なる反応を選べるようにする。**反応の理由は内部状態と経験にあり、無意味なランダム性に依存させない。**
6. 経験学習 A の既存 LOCK を維持する。経験により反応・好みの傾向が徐々に変化し、その長期傾向は再起動後も残る。一時的な気分・感情は平常へ戻る。学習 B は拡張可能な構造を維持し、実学習は後段。
7. 内面の変化を既存の目・視線・首・音声等の表現に反映する。身体や表情レンダラーを置き換える必要はない。

## 既存実装との境界
- 2026-10-21 時点の HeartState は mood / affection / curiosity / boredom / sleepiness / attention の6項目。
- Comfort と Social の意味上の独立性は LOCK するが、追加する数値フィールド、更新係数、相互作用式、保存方式、Behavior の選択則は **未決定**。
- EVA の Energy / Curiosity / Comfort / Social は比較の参考。Energy の独立変数化や既存6項目の削除は LOCK しない。
- 既存の反射優先順位・安全制御・神経入力意味化の LOCK を維持する。

## 実装前の確認
1. Heart の既存状態と Comfort/Social の責務重複を検査する。
2. Memory/Relationship と長期学習 A のデータフローを確認する。
3. 小さなテストで「同じ入力＋異なる状態→異なる自然な反応」「経験による傾向変化」「再起動時の一時状態リセットと長期傾向保持」を検証する。
