# LOCK 41｜傾向記憶は時間経過で薄れ、新しい経験で再強化される

更新日: 2026-09-17

## 決定
傾向記憶は一度形成されたら固定され続けるものではなく、**最近の経験によって強まり、新しい経験が途切れれば時間経過とともに徐々に弱まる**構造とする。

## 意図
Ghostが過去の生活パターンを永久に現在扱いしないため。

たとえば、以前は毎朝声をかけてもらっていたとしても、その習慣が長期間なくなれば「毎朝声をかけてもらうのが普通」という傾向は徐々に弱まる。一方で、同じ経験が再び続けば、その傾向はまた強くなる。

## 基本原則
- 傾向記憶は固定フラグではなく、強さを持つ状態として扱える
- 最近の同種経験が続けば傾向は強まる
- 新しい経験が途切れれば傾向は徐々に弱まる
- 過去の経験を即座にゼロへ戻すのではなく、時間をかけて薄れる
- 「昔よくあった」と「最近よくある」を区別できる構造にする
- 再び同種経験が増えれば、傾向は再強化できる

## LOCK 40との関係
LOCK 40で、反復イベントは必要に応じて個別記憶を残しつつ、頻度・継続・最近性などを材料に傾向記憶へ集約できることを定めた。

LOCK 41では、その傾向値を固定せず、**時間軸によって更新される生きた記憶**として扱う。

## 数値化について
傾向記憶は将来的に数値化できる構造とする。

数値化の材料候補には、少なくとも以下を含められる。
- 頻度
- 継続時間
- 最近性
- 反復の規則性
- その時のHeart Context
- Relationship

ただし、現段階では以下は固定しない。
- 数値レンジ
- 減衰率
- 更新周期
- 重み
- 閾値
- 計算式

これらは実装・観察段階で調整する。

## ゴールとの関係
この仕組みによりGhostは、単に過去ログを蓄積するのではなく、**最近の暮らし方に合わせて「いつものこと」を更新できる**。

これは「時間と記憶で内面が変化し、少しずつ関係性が育つ相棒」という最上位ゴールに沿う。
