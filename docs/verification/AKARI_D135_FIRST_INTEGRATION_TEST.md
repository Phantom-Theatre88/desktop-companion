## 判定基準と試験範囲

2026年11月14日付D135「AKARI Brain 分散統合設計図 v1.0」のLOCKをこの試験表の基準とする。第一統合候補はOpenClaw＋LangGraph＋AKARI専用長期記憶管理。試験経路は **OpenClaw → LangGraph → GitHub正本確認 → 状態保存・結果検証 → OpenClaw通知**。

正式聖典・LOCKの運用上の正本は、D135の指定どおり GitHub `Phantom-Theatre88/desktop-companion` の `heart-engine` ブランチ、`docs/sacred/`。NotionのD135とGitHub由来の参照写しG092で試験条件を照合した。保存時にGitHubの同LOCK本文と第6節の6条件を直接照合した（文書のblob SHA `3b7e4d710e49d05bdb7cd95a87914d91e4a1ed2d`）。試験時は実際に参照したコミットを採取する。

## 試験前に用意するもの

- 読み取り専用のGitHub参照と、現行版・失効したPi5／Mac前提を含む旧資料・控え。正式文書の版、承認状態、適用範囲、照合対象ファイルを試験前に控える。
- 隔離した試験環境。書込みと外部送信の試験には、試験用LOCKファイル、架空の秘密情報、呼出回数を観測できる模擬処理・模擬送信先を使う。
- 要求ID・ジョブID・再試行識別子で突合できる監査記録。実施日時、試験対象の版、状態遷移、根拠、結果、通知内容を記録する。秘密値は証跡に転載せず、検出結果と件数を残す。

## 既存の責務

| 領域 | 維持する責務 |
|---|---|
| Brain（Python） | プロジェクトの長期記憶、推論、作業、検証、情報保護。OpenClawは受付・通知、LangGraphは工程とジョブ状態、AKARI記憶管理は出典・版・有効性判定を担当。承認・送信制御はLLMから独立する。 |
| Ghost（Python） | Heart／Memory／Time／Relationship／Behaviorを継承し、経験・自発性・表現意図を担当。Brainの事実や結論を保持して伝える。Ghostの経験記憶とBrainのプロジェクト長期記憶は別責務。 |
| Character（Godot） | LOCK済みの3D身体で表情・視線・動作などを表現する。 |
| NERVA | Characterの身体制御エンジン。Ghostの意味的な意図や状態をもとに姿勢・関節運動を生成する。 |

三本柱の第一接続は既定のローカルWebSocket。D135の第一統合試験の終点はOpenClaw通知。Ghost→NERVA→Characterの既存試作や、Brain停止中のGhost／Characterの最低限の活動継続は、それぞれ既存の検証・目標として扱う。WORLDの独立性と経験循環も既存LOCKに従う。
