## 初期の視覚差分（スクショと設定画に基づく）

| 観点 | 設定画の特徴 | 現在の3D実機表示との課題 |
|---|---|---|
| 顔 | 大きく暖かい茶色の目、柔らかい頬と輪郭、幅のある表情 | 実機では顔つきが硬く、目と頬・口の魅力が十分再現されない |
| 頭髪 | 量感と流れのある高い茶色ポニーテール | 形状・揺れ・顔へのかかりが一体で可愛く見えない |
| 手・体 | 小さめの手、標準的で軽やかな骨格、自然な服のゆとり | 手の大きさと身体比率、肩・腰の印象に違和感 |
| 衣装・靴 | 8bit黒ポロ、黒カーゴ、黒系作業靴、腰装備 | 3D表示は青白いスニーカーで原画の靴と不一致、腰装備も不十分 |
| 姿勢 | 静止姿勢でも可愛い・自然な立ち姿 | 歩行・回頭・着座・待機で身体が不自然 |

## 次の制作物（Stage B）

1. 正面・側面・背面・斜めで破綻のない**新3D素体と頭部ブロックアウト**。既存GLBの顔や骨格への無条件の流用は禁止。
2. 設定画の三面図との**同一カメラ角・同一身長基準の比較画像**。前髪、目の配置、顎、頭身、手の比率、肩幅、脚、靴・衣装外形を目視で審査。
3. 正面と斜めで「可愛い」と判定できないモデルはリギング段階へ進めない。Blender本体等の造形実行環境は未整備のため、**3Dメッシュ新規制作はまだ未実施**。
4. Stage Bが通ったら実3Dの表情リグ→自然な待機→歩行・回頭・着座→Ghostとの自律統合へ進む。
