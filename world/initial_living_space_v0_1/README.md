# WORLD初期生活空間 v0.1：AKARI入室・実描画確認

2026-11-13 JSTにKimが承認した、入室・実描画の小ゴールの保存版です。内容の版はGodot実描画確認済みの制作反復v10を基準とします。

## 開く

復元ZIPを展開し、`godot/project.godot`をGodot 4.7.2で開いて実行してください。初回は画像・モデルの取り込みを待ちます。保存済みの確認環境はMac / Metal Forward+です。

1=室内、2=人物、3=足元、4=塔の形状、5=机とPC、6=鉢植え、7=本棚、0=人物の表示切替。4は形状確認専用の照明を使います。1〜3、5〜7では通常の光へ戻ります。

## 内容

- `godot/`：身体モデル・部屋モデル・画像・制御ソースを含む実行一式。`.godot`取り込みキャッシュは含めず再生成します。
- `godot/evidence/`：部屋・小物・エディターの実画面と検証記録。
- `blender/`：元の部屋のコピーと材質を焼いた部屋の保存ファイル。
- `production_tools/`：制作時の補助スクリプトの保存。制作環境のパスを含みます。復元の実行には不要で、自動実行しません。
- `manifest.json`：全保存ファイルのSHA-256。内容の取り違え・欠落を検出するための記録です。
- `LOCK_WORLD_INITIAL_LIVING_SPACE_V0_1_2026-11-13.md`：今回の小ゴールと未完了範囲。

上位WORLDの完成や、実在景観の精密再現、時刻天候連動、状態永続化、Brain／Ghost／NERVA接続の完成を宣言するものではありません。元の制作ファイルを上書きせず、この保存点を基準に後続版で改善してください。

## GitHub保存版と復元ZIPの関係

このディレクトリにはソース・証跡・manifest・artifact.jsonを収録し、大きな身体モデル・部屋モデル・画像・Blenderファイルは同名ZIPに保存します。Dropbox `/新ロボット/WORLD_INITIAL_LIVING_SPACE_v0.1_2026-11-13.zip` を展開し、その `godot/project.godot` を開いてください。GitHub側のソースのみで実行を試みないでください。`artifact.json` のSHA-256でZIPを照合できます。
