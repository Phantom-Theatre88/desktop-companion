# AKARI Room — WORLDの最初の3Dルーム

2026-11-12。独立起動する小規模なGodotプロジェクトです。**WORLD全体の完成ではありません。**

## 起動

Godot 4系で `project.godot` を開き、プロジェクトを実行（F6ではなくF5）。検証環境はGodot **4.7.2 stable / macOS**。最低バージョン・他OS・書き出したアプリの動作は未検証です。

```sh
godot --path world/akari_room
```

右ドラッグで視点、ホイールで拡大縮小、Rで視点を戻します。`+6h` / `+24h` は現実の現在から指定時間後の**時刻プレビュー**。`現在へ戻る` またはEscで、その時点の現実時間へ復帰します。終了して起動し直した場合も通常の現在表示から始まります。

## この段階で実装したもの

- 立体の部屋・床・窓・バルコニー、木製の机とノートPC1台、本棚と本、ベッド、ローテーブル、椅子、クッション、植物、室内照明。
- 原画の「左に本棚と机、中央に大窓とテーブル、右にベッド」を参照。招き猫は今回の明示指示に従い除去。
- 東京風の都市シルエットと塔。実在街区の再現やシミュレーションではありません。
- 編集可能な `.tscn` シーン、基本的な静的衝突形状、カメラと環境光。
- UTC epochで時計を保持し、JSTは明示的にUTC+9で表示。ホストのローカル時刻設定を使いません。
- `world_clock.gd` の一時的表示時刻と、`world_state.gd` の生活状態を分離。状態の診断用取得は深いコピーを返します。プレビューから生活状態への書き込み経路はありません。
- 夜／昼の光を時刻で概略的に切り替え。天気は常に「未接続」と明示。

## 責務境界

`world_state.gd` はWORLD内部の初期状態、`world_clock.gd` はWORLDの時計と表示プレビュー、`room.gd` は表示と管理者用操作です。プレビューはシミュレーションの経過時間ではなく、GhostのTime・経験記憶に渡しません。内部スナップショットは管理者向け診断用であり、Ghostへの知覚APIではありません。現段階のコピー保護はプロセス間権限制御の完成を意味しません。

本プロジェクトはWORLDの独立した開発ラインです。NERVA／Characterの既存プロジェクトや外観は変更せず、NERVAの完成を待つ依存関係も設けません。Brain=Python、Ghost=Python、Character=Godot、ローカルWebSocketの第一構成LOCKは維持します。今回のWORLD表示試作を、WORLDの最終言語・プロセス・通信形式のLOCKとはしません。

## 検証と再生成

```sh
godot --headless --path world/akari_room --script tests/test_room.gd
python3 world/akari_room/tools/build_scene.py
```

テストは失敗時に非ゼロで終了します。37チェック：JST日付境界・閏日・年跨ぎ、未来／過去プレビュー、現在への復帰、時刻の継続、深いコピー、状態汚染防止、家具・PC・本・窓・都市景観、床の物理照会、カメラ画角／拡大／リセット、昼夜の環境光、天気未接続表示を確認します。

`tools/build_scene.py` は標準Pythonのみを使い、部屋と4つの家具シーンを再現可能に生成します。生成後に `.tscn` を手編集すると、再生成時にその編集は上書きされます。寸法・家具配置は試作値です。GodotのインポートキャッシュはGit対象外です。

実描画を確認できる環境では、次のように画面を保存できます（ヘッドレスでは使用不可）。日時はUTC epochで指定します。これは管理者向け検証引数で、通常起動に指定は不要です。

```sh
godot --path world/akari_room -- --capture=/absolute/path/room.png --preview-utc=1794468600
```
